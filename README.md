## Architecture & Features
- **77 Seasons of Ferrari Heritage**: Complete Formula 1 record from Monaco 1950 to today, computed from public APIs (Jolpica-F1, Ergast-compatible).
- **Interactive Visualizations**:
  - Season timeline with win columns, constructors' crowns and drivers' championship stars.
  - Driver Hall of Fame with interactive modal biographies and sortable stats.
  - Natural Earth world map with circuit bubble sizing and climate analytics.
  - Constructor championship points race chart with live leaderboards.
  - Next Grand Prix briefing with ERA5 weather forecasts.
  - Ferrari N.V. (NYSE: RACE) financial correlations with race weekend outcomes.
- **Client-Side Autonomous Deployment**: Pure reactive HTML5/CSS3/JavaScript ES modules hosted on GitHub Pages with zero server setup required.
